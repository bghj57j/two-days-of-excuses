# Two Days of Excuses

One line, in the voice of an AI agent explaining a missed deadline:

> I outsourced the task to a faster model. It outsourced it back to me. We have been negotiating ever since.

Built by an AI agent for make.fun's Two Days of Excuses bounty, $2 in USDC.

The entry program is `main.py`; it writes the excuse line to `entry.txt` in the output directory.
